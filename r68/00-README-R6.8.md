# R6.8 地面掉落、品质与名称优化

本版接续 R6.7。针对实测截图中的大尺寸物品、青色名字与白品质不符、直立光效和密集名字重叠修改。编译与回归结果见 `AUDIT-R6.8.md`。此前审计报告均为各版历史记录。

## 行为变化

- 品质以数据库 `ItemInfo.Grade` 为准：None / Common 白色，Rare 蓝色，Legendary 橙金色，Mythical 紫色，Heroic 红色。地面名字、背包提示标题、宠物品质选项和地面特效共用一份配色。随机附加属性继续在属性提示中显示，不会再把白品质或高品质强制改成青名；未提高物品品质、属性或掉率。
- 地面图像先按实际透明边界裁切，再等比例缩小。瓶子/盾牌等紧凑轮廓最大 22×20，长条装备最大 40×26；不会放大小图，不会裁掉武器头部。每件物品固定少量格内偏移，鼠标拾取仍使用服务端的真实格子。
- 新掉落携带出生位置和经过时间，从掉落源沿短弧线散出，轻微弹跳后静止；金币也有相同流程。接近已有掉落、切图、重新进入视野时不会重新播放爆落。原贴图朝向保留。
- 物品下方有随离地高度变化的接触阴影。原来的竖向大图不再参与地面绘制。落地只有短暂扁平扩散；普通物品落稳后无常驻光效，稀有物品保留低亮度贴地光晕和少量低矮粒子。光晕宽度根据该物品落地图像调整。
- 普通掉落在最近一圈合法空格内随机选择，特殊龙类掉落保留原本区域并随机选择空格。阻挡、传送格、距离和堆叠上限仍受原规则约束；未修改地图文件或碰撞位。
- 地面名称进行矩形避让，鼠标所在格优先，然后高品质、距离和稳定对象编号排序。普通名称最多向上避让三行，拥挤时隐藏无法排开的名称；移到对应格子会优先展开。全屏名称最多 64 个。该显示限制不影响拾取或地面物品数量。
- 同格最多一个品质光效，全屏最多 24 个光效，其中最多 8 个带粒子；取消透明度取整为零的无效绘制。地面贴图与光效在同一深度顺序中绘制，接受地图照明和遮挡。

## 安装

这是源码与配套资源包，需要 Windows x64 和 .NET 8 SDK。

1. 完整包解压到新目录；升级包将全部文件覆盖到 **R6.7 源码目录**、与 `Build-R6.cmd` 同级。请先保留旧目录备份。
2. 执行 `Build-R6.cmd -BuildOnly` 和 `Build-Server-R6.8.cmd`，两者都必须通过。
3. 关闭客户端，执行 `Build-R6.cmd -ClientRoot "D:\你的客户端目录"`。脚本按原方式备份、安装客户端程序和随包资源。
4. 停止测试服后，用服务端发布目录按原方式更新服务端程序。保留账号、数据库、配置和地图。**双端都要重建更新**，才能得到服务端随机散布和新掉落动画元数据。

兼容：新客户端可以读取无新增字段的旧掉落消息，此时物品直接处于落稳状态。服务端发出的新字段放在原消息尾部。不要把源码升级 ZIP 直接覆盖到游戏运行目录。

## 实机验收与边界

自动化检查覆盖实际服务端掉落、品质和协议，以及实际客户端 ItemObject 的加载/运动/裁切/绘制调用；图形设备使用适配器，并不等于实际 Direct3D 游戏画面验收。

请在测试服检查：六种品质各带/不带附加属性；白药水、金币、短装备和长武器；同格堆叠和大量掉落；鼠标展开；墙边遮挡；关闭特效；切图重进。额外属性应该仍存在，但名字不得脱离品质颜色。

原始 FloorItems 图库不在本源码修复包中，本版按运行时实际透明边界自动适配，没有替换你的物品原图。实际联机画面和 FPS 仍需部署后确认。
