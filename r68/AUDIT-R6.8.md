## 已定位并修正

1. 两个服务端 ItemObject 构造函数均优先把 IsAdded 物品设为 Cyan，覆盖真实品质。改用共享品质配色；客户端也按消息中的 grade 着色。未改变实际品质或附加属性。
2. 旧客户端仅用可见尺寸计算位置，仍绘制整个原图，透明边距和原图尺寸与世界占地不一致。现在实际裁切可见像素、等比例缩小，绘制矩形与用于可见性判断的显示矩形一致，拾取仍按服务端格子。
3. 旧特效无论物品大小都画 96×192 的竖向素材。现在完全停止调用 0—4 号竖图，只调用中性的扁平扩散、软光斑和小光点。特效尺寸取自物品占地，颜色与名字共用策略。
4. 原物品没有运动，随机掉落取第一个扫描到的空格。现在增加出生源/经过时间字段，物品沿抛物线散出并落稳，使用小幅固定格内偏移和地面阴影。服务器在合法空位中随机选择，保留邻近优先及原有落地限制。
5. 特殊龙类掉落原本把矩形区域套用了方形边缘的 x 步长，导致只扫描少数边缘点；恢复逐格扫描原区域，再随机选择空位。
6. 原地面名字全部直接绘制，容易重叠。现在按鼠标所在格、品质、距离、对象编号决定优先级，再做有界矩形避让。隐藏的只是拥挤名称，未隐藏实际物品。
7. 地面光效上限改为 24 / 8（总数 / 带粒子数），普通物品不常驻发光，同格只选一个，零透明度和缺失物品图像不提交孤立特效。

## 测试边界

奖励测试使用真实服务端 ItemObject、地图格子和消息序列化：检查附加属性不覆盖六种品质；验证新旧物品协议、金币协议、出生点和时间；反复检查普通/龙类掉落分布；阻挡/传送格不能掉落、堆叠上限不能突破。R6.7 的伤害归属与任务奖励测试全部保留。

掉落客户端测试链接真实 ItemObject.Load / Process / Draw、尺寸策略、效果绘制器、预算器和名称排布，图形设备/图库读取使用适配器。覆盖带透明边距的超大素材、紧凑图与小图、实际裁切区域、运动终点、最终缓存失效、金币落地、旧物品不重播、无竖向图绘制、名色一致、缺图不发光和密集名称不重叠。

以上不代表真实 Direct3D 联机画面或 FPS 已验收。用户原始 FloorItems 图库未包含在本修复包中，运行时自动适配其可见像素；仍需按 README 在测试服检查最终观感。旧 R6.4/R6.5 效果预览属于历史方案。
