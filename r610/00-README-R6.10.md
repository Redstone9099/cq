# R6.10 密集掉落与同格显示优化

接续 R6.9，保留该版落地扩散、品质光环、闪点和地牢局部照明。本版集中修正显示排序并减少无效处理，未加入背包整理、回收或寄售功能。

## 本轮修改

- 同格掉落按低品质到高品质绘制，高品质不会被后落下的普通物品盖住。同品质以稳定对象编号排序，顶层物品与该格品质光效的代表物品保持一致。人物仍在掉落物品上方绘制。只改变客户端显示/鼠标命中的显示对象，不改变服务端按格拾取的物品顺序、归属或数量。
- 名称达到既有 64 个上限后立即停止后续名称解析；每个显示的名字只解析一次。鼠标所在格仍最优先，原有品质/距离优先和矩形避让保留，没有进一步降低名称上限。
- 完全位于屏幕外的抛落不再使可见地图缓存反复失效。边缘阴影、出屏前的最后位置、重新入屏和最终落地仍触发必要的重绘。
- 没获得特效名额的物品提前退出，不再重复查询特效图库。视觉参数、24/8 特效名额与四个落地预留名额均不变。

## 安装

本包为源码与配套资源，需要 Windows x64 / .NET 8 SDK。累计升级 ZIP 同时适用于 R6.8 或 R6.9 源码根目录；完整 ZIP 解压到新目录使用。

1. 备份源码目录，将升级包全部覆盖到与 `Build-R6.cmd` 同级的位置。
2. 先运行 `Build-R6.cmd -BuildOnly`，全部编译和回归通过后关闭游戏。
3. 运行 `Build-R6.cmd -ClientRoot "D:\你的客户端目录"`，由原脚本备份并安装客户端。
4. 服务端已经是 R6.8 / R6.9 的，无需更新服务端。更老服务端应按 R6.8 文档升级，以支持掉落起点/经过时间字段。

不要把源码升级 ZIP 直接覆盖到游戏运行目录。原先的地图、数据库、账号和配置不在覆盖范围内。
