# R6.9 掉落效果可见性与落地反馈

本版在 R6.8 基础上增强掉落效果。保留自然抛落、物品大小、名称避让、真实品质配色和伤害归属修复。本次修改仅涉及客户端显示，背包整理、批量出售和直接寄售尚未加入。

## 修改

- 原品质光斑范围小、透明度低，又先于物品绘制，容易被物品自身覆盖。现在稀有及以上物品有伸出物品底边的扁平品质光环，淡入并轻微呼吸；低细节模式仍保留光环。
- 小闪点在物品本体之后、同一个地图深度顺序内绘制，随品质增加到 1 / 2 / 3 / 3 个；仍受后续地图行和人物遮挡，没有竖向光柱。
- 落地扩散有明确的冲击、扩张、消散关键帧，与真正落地时刻同步；白色/普通物品和金币只有这一段短暂反馈，落稳后不持续发魔法光，未伪造品质。
- 稀有以上掉落为地牢光照遮罩提供一小片局部照明，防止地面光效在暗处被完全压掉。仍遵守特效开关和致盲光色，未修改地图文件或碰撞。
- 全屏最多 24 个效果，其中最多 8 个有闪点；预留最多 4 个落地名额，避免老掉落挤掉全部新掉落反馈。同格优先显示最高品质。
- 原有品质表不变：None / Common 白色，Rare 蓝色，Legendary 橙金色，Mythical 紫色，Heroic 红色；附加属性不改变品质。地面多数物品若是白品质，仍不会全部变成蓝色发光物品。

## 安装

这是源码与资源包，需要 Windows x64 和 .NET 8 SDK。

- 已安装 R6.8：将升级 ZIP 的全部文件覆盖到 **R6.8 源码根目录**，与 `Build-R6.cmd` 同级。先执行 `Build-R6.cmd -BuildOnly`；通过后关闭游戏，再执行 `Build-R6.cmd -ClientRoot "D:\你的客户端目录"`。本次只需重新构建安装客户端，服务器沿用 R6.8。
- 完整包：解压到新目录，按上述方式构建客户端。若仍使用 R6.7 或更早的服务器，须同时执行已有 `Build-Server-R6.8.cmd` 并更新服务端，以获得 R6.8 的掉落位置和时间字段。
- 不要将源码升级 ZIP 直接覆盖到游戏运行目录。原安装脚本继续提供文件校验、回归门禁和备份。

## 实测关注

游戏设置里的特效开关应为开启。分别查看普通药水/金币落地、稀有以上持续光环、暗地牢和明亮地图、同格叠物、密集掉落、拾取/切图清理和关闭特效。

Windows 编译、回归以及离线像素检查的实际结果见 `AUDIT-R6.9.md`。这些检查不等于真实 Direct3D 联机画面或 FPS 测量；物品原始 FloorItems 图库不在修复包中，尺寸仍在运行时适配。
