## 旧包问题的复现

使用 SHA256 固定的原始 R6.6 包（其奖励回归与 R6.5 相同）先复现 C# `CS0747`，仅修正初始化器后再运行旧测试，记录到：

```text
BASELINE AREA: rate=0, dealt=0, HP=1000
BASELINE POISON: HP=600, dead=False, owner=none
```

因此旧失败并不是“已扣 600 的 A 被只扣 400 的 B 抢走归属”，而是初始倍率 0 导致 A 根本未扣血，怪物未死亡。生产对象初始倍率现为 1；新测试在第一个状态处理前和之后都记录到：

```text
A=600, B=400, HP=0, owner=P1
```

新增断言检查真实生命变化、最终死亡、有效伤害胜者和实际地面物品保护；还执行真实绿毒/流血处理，确保临时仇恨/经验归属不会替代死亡结算结果。没有删除或跳过失败断言。

## 其余修正

- 初始化器改为字段初始化后单独 Add，随机分组掉落测试含义不变。
- UI 回归工程排除独立的 DirectLaunchRegression 入口；该检查仍单独编译、执行。
- 客户端怪物的 byte Effect 字段遮蔽同名类型，静态清理调用改用完整类型名。
- 所有安装前回归与客户端/服务端发布前强制重编译，避免 ZIP 覆盖后误用较新的旧 bin/obj 文件。
- 人物/英雄物品快捷栏移除旋转按钮、键位与方法；保留废弃枚举编号以兼容其余已存键位。
- 技能栏箭头收起整个栏体和原点击范围，只留展开按钮；两条栏独立，恢复时刷新当前绑定与冷却。
