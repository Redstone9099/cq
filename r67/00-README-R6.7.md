# MIR2 R6.7：修正构建阻塞、伤害初始倍率与快捷栏操作

本版接续 R6.6，包含此前 110 个技能图标、快捷栏图标尺寸修复及掉落关键帧特效。**保留所有安装前回归，不提供跳过失败测试的安装方式。** 旧版报告是历史记录，以本说明及 `AUDIT-R6.7.md` 为准。

## 两个构建阻塞的实际原因

1. `RewardsRegression.cs` 中 `GroupDropInfo` 初始化器混写字段赋值和集合元素，触发 C# `CS0747`。已改为先设置 `Random=true`，再添加掉落项，保留原测试含义。
2. `MapObject` 的受伤/护甲倍率初始值为 0，只有运行 `ProcessPoison` 后才变成正常的 1。旧测试直接新建怪物，所谓 A 的 600 伤害实际被乘成 0；B 毒伤 400 后怪物还有 600 血，并未死亡结算，归属为空。Windows 已复现这个过程，**不是 A 已扣 600 血后被 B 的 400 血覆盖归属**。

生产代码现在从创建起使用 1 倍初值。测试增加真实扣血与死亡前置断言，并检查实际落地物品的拾取保护；覆盖首个状态处理前/后、先毒后范围伤害、护甲减伤、增伤、过量毒伤及显式 0 倍免伤。没有改变按有效伤害竞争掉落的规则，也没有把每次毒伤强制判给之前的玩家。

全量构建还发现并修正了 UI 回归工程误包含独立启动检查程序的问题。启动检查仍在客户端发布后单独执行。各回归与客户端/服务端发布前均强制重新编译，防止压缩包覆盖后因文件时间较旧而继续使用旧 bin/obj 产物；旧包复现与新包检查使用不同目录。

客户端编译中还修正了怪物的 `Effect` 字节字段与 `Effect` 类型同名导致的静态方法解析错误；明确调用特效类型的清理方法，保留原有特效释放行为。

## 快捷栏操作

- 人物物品栏、英雄物品栏固定横向。移除旋转按钮及默认旋转快捷键，旧配置中的旋转绑定不再载入。保留旧枚举编号，避免其后所有快捷键发生编号偏移。
- 技能栏箭头现在收起整条栏：格子、技能图标、序号和冷却遮罩一起隐藏，原来的大块点击区域也缩成 20×20 的展开按钮。
- 两条技能栏独立收起。点击展开按钮恢复整条栏，并重新刷新绑定和冷却；收起期间结束的冷却不会残留。
- 原有“显示/隐藏技能栏”快捷键仍可用（默认 `R`，以你的设置为准）；整体重新显示时会展开栏体。系统选项中的技能栏开关仍保留。

## 安装

这是源码与配套资源包。Windows x64 与 .NET 8 SDK 下：

```powershell
# 先构建和运行全部客户端前置回归，不改已安装游戏
.\Build-R6.cmd -BuildOnly

# 构建服务端并运行奖励回归，输出独立目录，不自动部署
.\Build-Server-R6.7.cmd

# 通过后，指定已有游戏目录安装客户端，脚本会备份
.\Build-R6.cmd -ClientRoot "D:\你的客户端目录"
```

**本次包含服务端代码修改，需要重新构建并更新服务端。** 关闭测试服、完整备份后，按现有方式部署服务端发布目录的程序和运行时，保留数据库、账号、INI 与地图。这里没有自动连接或修改你的运行中游戏/服务器。

- 完整包：`Mir2_R6_7_Rewards_Hotbar_Fixed_20261024.zip`，完整解压到新目录即可构建。
- 升级包：`Mir2_R6_7_R65_R66_Upgrade_20261024.zip`，适用于此前交付的 R6.5 或 R6.6 源码目录；备份后将全部内容合并到 `Build-R6.cmd` 同级，再构建。只修改过旧测试初始化器的目录也会被本版正确文件覆盖。
- 不确定基包、文件缺失或校验失败时，使用完整包。不要把源码升级包直接覆盖到游戏运行目录，也不要只拷贝技能图库。

## 验证与回退

最终 Windows 编译/回归结果及对应源文件哈希保存在 `Evidence/R6.7/windows-ci.json`，构建记录链接见审计报告。`Verification/verify_r67_review.py` 检查当前文件与这些测试输入一致；`Tools/verify_package.py` 检查完整文件清单。

旧包问题的独立复现脚本为 `Verification/Reproduce-R65.ps1`，只对另一个未修改的 R6.5/R6.6 解压副本运行。它故意验证旧版本失败，然后修复后的正式构建仍必须通过全部回归。

自动化构建不等于联机验收。测试服仍需检查：两人 600/400 的真实扣血与拾取、毒/范围技能最后一击、重生后第一击，以及两条技能栏收起/展开、冷却结束、改绑、缩放和切图。

客户端回退使用 `Restore-ClientBackup.ps1` 和本次 `_r6-backup-*`。服务端回退使用部署前完整备份。
