## 已包含的界面与操作改动

- **任务列表**：重排为左侧任务选择、右侧内容和奖励，8 行可见任务。恢复 Prguse 原版任务状态图标；无图标状态不绘制，避免把索引 961 的整张窗口误当小图标。清理正文中的重复任务图标。
- **任务奖励**：明确显示经验、金币、元宝，固定奖励和任选奖励分区。只有数值奖励时收紧为 44 像素，把阅读空间留给正文；有一种物品奖励时 120 像素，两种都有时 202 像素。切换任务清理旧奖励格，保留任选奖励的原始服务端索引。
- **任务操作**：原来的“离开”按钮被纳入统一布局，改为底部“返回对话”，不会再留在奖励区。接受与完成共用右下角位置，按任务状态互斥显示。空列表提供说明，不再顺带关闭 NPC 会话。
- **对话**：选项按顺序排成 1～3 列，最多 18 个直接展开，不使用选项滚轮；19 个以上使用明确的翻页按钮。正文独立滚动，长选项有完整提示。保留行内链接及服务端脚本键。任务入口恢复原有 Title 动画按钮，不叠加另一个任务图标。
- **返回流程**：保存原始菜单内容与 NPC 身份，进入服务后保留会话；返回时先恢复菜单，再发 `[@MAIN]` 重新获取真实主对话。拒绝返回后的服务数据重新打开旧商店。空服务对话会等待后续商品/出售包，若没有服务到达则收起空页面。
- **购买 / 出售**：统一窗口材质、买卖页签与固定底栏。商品行加宽；数量确认保留总价。出售为点选背包、核价、确认，去掉多余的“点选背包开关”；退出出售解锁暂存物品。数量确认在窗口已关闭、NPC 已更换或商品已失效时不会发送旧购买请求。
- **攻击指针**：恢复普通攻击 440ms、强制攻击 475ms 的 1 倍动作时长。悬停同一目标时，每次动作结束停顿 650ms 再自动播放，周期约 1.09 / 1.125 秒。点击可在上一动作结束后立即重播；快速连点不会反复截断动作；移到界面或切换目标会立即切换状态。动作素材、刀光、静止像素及热点均保留。

## 使用

1. 备份原 R6.3 源码目录，再将本补丁的全部内容覆盖进去，关闭游戏。你的现有游戏应已安装当前 R5.1 所需资源；完整地图、声音、怪物/坐骑/宠物库不包含在源码包内。
2. 构建电脑需要 **Windows x64 与 .NET 8 SDK**。双击 `Build-R6.cmd`，默认游戏目录为 `D:\Crystal-Preview\Client`。
3. 目录不同时运行：

   ```powershell
   .\Build-R6.cmd -ClientRoot "D:\你的游戏目录"
   ```

4. 只构建、不改现有游戏：

   ```powershell
   .\Build-R6.cmd -BuildOnly
   ```

脚本先校验包、运行掉落/任务、呈现、会话/布局/鼠标与既有 UI 回归、发布同一份 win-x64 自包含客户端，并检查编译后的直接启动入口；通过后才备份和安装程序、运行时及随包 UI/指针文件。它保留现有 INI、地图及其它游戏数据，也不要求重新选择无关的宠物图库。运行游戏所需的 DirectX 等条件仍由现有客户端决定。

安装完成后手动运行游戏目录里的 `Client.exe`。日志位于 `build-logs`，备份位于游戏目录 `_r6-backup-*`。构建失败不安装，安装过程中失败会尝试按已核验备份恢复。手动回退：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Restore-ClientBackup.ps1 -BackupRoot "D:\你的游戏目录\_r6-backup-具体目录"
```

## Windows 实机验收

- 同一个 NPC：对话 → 购买 → 商品子列表 → 返回商品 → 返回对话 → 再次购买，菜单与选择均正确。
- 支持买卖的 NPC：购买 ↔ 出售；点选物品后返回，背包物品不再锁定；关闭数量框后不能误发旧交易。
- 切换 NPC，关闭并重新打开，或走远后重开，不显示上一位 NPC 的菜单。
- 1 / 8 / 18 / 超过 18 个对话选项；正文很长或有行内链接时，选项仍可点击且不被正文滚动影响。
- 无任务、1 个任务、超过 8 个任务；任务名称较长；金币/经验、固定物品、任选物品的各种奖励组合；接受、完成、返回对话。
- 悬停怪物至少 10 秒应持续按约 1.1 秒周期播放；连点、换目标、移到 UI、失焦；普通与强制攻击均测试。
- 用户实际分辨率下窗口底栏、关闭按钮、背包与任务详情仍可触达。
