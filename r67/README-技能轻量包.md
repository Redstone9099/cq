# 当前使用 R6.7 升级包

最新入口为 `00-README-R6.7.md`。`Mir2_R6_7_R65_R66_Upgrade_20261024.zip` 可合并到此前的 R6.5 或 R6.6 源码包，包含技能图标及构建/伤害倍率/快捷栏操作修复。本次还需要构建、部署服务端。下面是 R6.6 技能包适配记录。

# 技能包：适配 R6.5 / R6.6

此次使用你上传的 110 个技能图标，资源库原字节保留。原上传说明提到的 v7 与 `Build-And-Install.ps1` 不适用于这次基包，已经改接现有 `Build-R6.cmd`。

- **完整包**：直接完整解压，按 `00-README-R6.6.md` 构建和安装。
- **轻量升级包**：基包必须是 `Mir2_R6_5_Fixed_Effects_20261024.zip`。备份后，将轻量包全部内容合并到 R6.5 源码顶层，再运行 `Build-R6.cmd -BuildOnly`，通过后用 `-ClientRoot` 指定游戏目录安装。

轻量包包含接口与绘制修复；不能只拷贝技能 `.Lib`，也不能只覆盖最初上传的 `SkillIconsV6Module.cs`，否则旧程序仍按原版尺寸绘制或接口不匹配。

包含：110 个 128×128 图标（按 Spell ID 存入 256 个帧位）、快捷栏/技能书/绑定窗口接入、对应冷却遮罩尺寸修复、验证脚本和本次差异文件。不包含独立编辑 PNG，也没有新编译的客户端程序。

构建入口会自动执行 `Verify-SkillPackage.ps1`、`SkillArtworkRegression` 与既有回归。完整安装方法、验证边界及预览位置见 `00-README-R6.6.md`。
